## ⚡ Game Highlights

* **🎭 Secret Identities:** Players are assigned as **Honest Collectors** or **The Secret Fraudster**.
* **💸 Fraudster Heist:** The Fraudster knows which items are fake. When a Collector buys a fake, **100% of the bid money goes straight to the Fraudster!**
* **🤖 Smart AI Bidders:** Automated bots fill open slots dynamically for seamless solo testing or group play.
* **⏱️ Bidding Arena:** Features real-time countdown timers, late-bid extensions, and active ticker logs.
* **🎵 Dynamic Audio & FX:** Web Audio API sound synthesis and celebration confetti.
* **🚪 Total Session Control:** Clean exit options from any stage of the game.

<br />

## 🛠️ Technology & Architecture

Built pure frontend for instant loading speeds and zero build dependencies:

| Technology | Purpose & Implementation |
| :--- | :--- |
| **HTML5** | Viewport layouts, game screens, and modal overlays |
| **Tailwind CSS** | Custom glassmorphism UI, dark mode theme, responsive grids, and animations |
| **JavaScript (ES6+)** | Object-Oriented game engine, player states, bot logic, and score calculations |
| **Web Audio API** | Procedural sound engine (`SoundEngine`) generating real-time synth audio for gavel knocks and bid pings |
| **Canvas Confetti** | Particle effects triggered on genuine item victories |
